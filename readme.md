# UAV aerial photography dataset for sheep and cattle detection with VOC+YOLO format, 1021 images in 3 categories.

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 1021

Number of annotations (number of xml files): 1021

Number of annotations (number of txt files): 1021

Label category count: 3

Label category names (Note that the order of yolo format categories does not correspond to this, but is based on the classes.txt in the labels folder): ["cattle", "cow", "sheep"]

Number of boxes labeled in each category:

cattle Frames = 4128

Cow Frames = 401

Sheep Frames = 9518

Total frame count: 14047

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
